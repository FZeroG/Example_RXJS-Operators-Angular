Basic to Advanced RxJS

อ่านและควบคุม Observable Flow ใน Angular ด้วย RxJS Operators

คู่มือสำหรับอ่าน flow ของ Observable ใน Angular ให้เข้าใจง่ายขึ้น: แต่ละ operator รับค่าอะไรจาก stream, คืนค่าอะไรออกไป, และควรใช้เมื่อใด. ครอบคลุมตั้งแต่การแปลงค่า กรองค่า หน่วง input จัดการ error ไปจนถึงการควบคุม request หลายชุดและการ cache ผลลัพธ์.

Operator Map

ภาพรวม Operators ที่ควรรู้ ตั้งแต่พื้นฐานถึง Advanced

Basic

map

รับค่าเดิมจาก stream แล้วคืนค่าใหม่ เช่น เลือก field หรือคำนวณค่าเพิ่ม

Basic

filter

ปล่อยค่าต่อเมื่อเงื่อนไขเป็นจริง เช่น keyword.length >= 2

Basic

tap

แทรก side effect เช่น log หรือ set loading โดยไม่แก้ค่าที่ส่งต่อ

Basic

startWith

emit ค่าเริ่มต้นทันที ก่อน valueChanges หรือ API จะส่งค่าจริง

Timing

debounceTime

รอให้ input หยุดเปลี่ยนช่วงหนึ่ง แล้วค่อยปล่อยค่าล่าสุด

Filtering

distinctUntilChanged

ข้ามค่าที่ซ้ำกับค่าก่อนหน้า ลด API call ซ้ำจาก input เดิม

Error

catchError

จับ error แล้วคืน Observable สำรอง เช่น of([]) หรือ of(null)

Cleanup

takeUntil

unsubscribe stream เมื่อ notifier emit เช่น component destroy

Loading

finalize

รัน callback ตอน stream จบ error หรือถูก unsubscribe เหมาะกับปิด loading

Flattening

switchMap

map ค่าเป็น request ใหม่ และ cancel request เก่าเมื่อ source emit อีกครั้ง

Flattening

mergeMap

map ค่าเป็นหลาย request ที่ทำพร้อมกัน เหมาะกับงานอิสระ

Flattening

concatMap

map ค่าเป็น request แบบต่อคิว รอให้ตัวก่อนหน้า complete ก่อน

Flattening

exhaustMap

ระหว่าง request ทำงานอยู่ จะไม่รับ event ใหม่

Combination

forkJoin

เริ่มหลาย Observable พร้อมกัน แล้ว emit เมื่อทุกตัว complete

Combination

combineLatest

รวมค่าล่าสุดจากหลาย stream แล้ว emit ใหม่เมื่อ stream ใดเปลี่ยน

Sharing

shareReplay

share subscription และ replay ค่าล่าสุดให้ subscriber ใหม่

Example

Search flow

valueChanges -> debounceTime -> distinctUntilChanged -> switchMap ไปยัง HTTP search

Dashboard load

forkJoin รวม profile$, orders$ และ alerts$ แล้ว render เมื่อ complete ครบ

Angular Code

ตัวอย่างโค้ด Angular สำหรับ Operators สำคัญ

readonly results$ = this.searchControl.valueChanges.pipe(
  debounceTime(300),
  distinctUntilChanged(),
  filter((keyword) => keyword.trim().length >= 2),
  switchMap((keyword) =>
    this.productService.search(keyword).pipe(
      catchError(() => of([]))
    )
  )
);
readonly products$ = this.productService.getProducts().pipe(
  map((products) => products.map((item) => ({
    id: item.id,
    name: item.name,
    priceWithVat: item.price * 1.07,
    inStock: item.stock > 0,
  }))),
  filter((products) => products.length > 0),
  tap((products) => console.log('loaded products', products.length)),
  startWith([])
);
// switchMap: งานใหม่แทนงานเก่า
route.params.pipe(
  switchMap(({ id }) => this.userService.getUser(id))
);

// mergeMap: ทำพร้อมกัน เหมาะกับงานอิสระหลายชิ้น
from(files).pipe(
  mergeMap((file) => this.uploadService.upload(file), 3)
);

// concatMap: ทำเรียงลำดับ เหมาะกับ save queue
from(changes).pipe(
  concatMap((change) => this.documentService.save(change))
);

// exhaustMap: กันกดซ้ำระหว่าง submit
submitClick$.pipe(
  exhaustMap(() => this.authService.login(this.form.getRawValue()))
);
// forkJoin: รอ HTTP ทุกตัว complete แล้ว emit ครั้งเดียว
readonly dashboard$ = forkJoin({
  profile: this.userService.getProfile(),
  orders: this.orderService.getRecentOrders(),
  alerts: this.alertService.getUnreadAlerts(),
});

// combineLatest: รวมค่าล่าสุด เหมาะกับ filter + sort + data
readonly visibleProducts$ = combineLatest([
  this.products$,
  this.categoryControl.valueChanges.pipe(startWith('all')),
  this.sortControl.valueChanges.pipe(startWith('popular')),
]).pipe(
  map(([products, category, sort]) => filterAndSort(products, category, sort))
);
readonly user$ = this.http.get<User>('/api/me').pipe(
  retry(2),
  catchError(() => of(null)),
  finalize(() => this.loading.set(false)),
  shareReplay({ bufferSize: 1, refCount: true })
);

ngOnInit() {
  this.socket.messages$.pipe(
    takeUntilDestroyed(this.destroyRef)
  ).subscribe((message) => this.messages.update((items) => [...items, message]));
}
